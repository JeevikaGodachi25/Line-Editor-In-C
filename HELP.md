# Line Editor - Help

## INSERT

Inserts a new line at the specified line number.

**Usage:**

```text
EDITOR > INSERT
Enter line number to insert: 1
Enter text: Hello World
```

---

## DELETE

Deletes an existing line from the document.

**Usage:**

```text
EDITOR > DELETE
Enter line number to delete: 1
```

---

## DISPLAY

Displays all current lines with their line numbers.

**Usage:**

```text
EDITOR > DISPLAY
```

---

## SAVE

Saves the current document to a text file.

**Usage:**

```text
EDITOR > SAVE
Enter filename to save: document.txt
```

---

## LOAD

Loads the contents of a text file into the editor.

**Usage:**

```text
EDITOR > LOAD
Enter filename to load: document.txt
```

---

## SEARCH

Searches for a word or text in the document and displays the matching line numbers.

**Usage:**

```text
EDITOR > SEARCH
Enter text to search: Hello
```

---

## COUNT

Displays the total number of lines and words in the document.

**Usage:**

```text
EDITOR > COUNT
```

---

## HELP

Displays the list of available commands.

**Usage:**

```text
EDITOR > HELP
```

---

## EXIT

Exits the line editor and releases the allocated memory.

**Usage:**

```text
EDITOR > EXIT
```
